# 官网 MVP 页面信息架构与验收

## 目标

让首次访问的学生在手机上快速回答三个问题：协会是谁、最近做什么、如何加入。页面先服务公开宣传和历史沉淀，不提前承载登录、后台、OJ 判题或实时榜单。

## 页面结构

| 页面 | 必须回答的问题 | 主要内容 |
|---|---|---|
| 首页 | 协会是谁、为什么加入 | 定位、四项全国性竞赛荣誉、近期活动、加入入口 |
| 协会介绍 | 协会如何运行 | 简介、方向、公开成员/指导信息、发展历程 |
| 活动 | 协会做过什么 | 按年份/类型浏览，列表到详情，时间地点和报名状态 |
| 成果 | 有哪些结果 | 竞赛获奖、项目成果、算法/开发类荣誉和来源 |
| 知识与文章 | 可以继续学什么 | 公开审核的文章、学习资料和来源说明 |
| 加入我们 | 如何参与 | 零基础、新生、竞赛方向和联系/报名入口 |

## MVP 验收

- 首页首屏能看到协会定位、四项全国性竞赛荣誉、近期活动和加入入口。
- 所有页面在手机和桌面宽度下可浏览，不出现横向溢出。
- 导航、菜单、卡片和表单入口支持键盘操作，有清晰焦点和当前页状态。
- 活动和成果列表支持至少一种稳定筛选方式；无数据时给出说明和下一步。
- 公开文章和素材都有来源；未审核内容不会出现在公开页面。

## 明确不放入 MVP

登录、角色权限、会员中心、复杂后台、评论/论坛、OJ 判题执行、ECPC 实时榜单和完整微服务集群。
