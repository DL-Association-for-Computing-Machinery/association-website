# 主站基线

决策日期：2026-09-21

Jasper-Liao2026 的 Demo 是主站首页的视觉与交互基线。生产骨架已在 `main` 使用 `create-next-app` 初始化为 Next.js App Router、TypeScript、Tailwind CSS 和 pnpm，首版实现位于 `src/app/`。

`prototype/` 保留完整原型、素材、组件和验收截图，作为视觉参考；`demo/` 与其他原型目录不参与主站覆盖，后续可分别发展为开发组宣传站。

当前主站已包含开屏动效、浅深色主题、响应式导航、协会介绍、竞赛荣誉、活动回顾、学习方向和加入入口。内容模型、内页、CI、部署和宣传站跳转留到后续阶段。网站运行不需要飞书访问凭证。
