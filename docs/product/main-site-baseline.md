# 主站基线与宣传站点规划

决策日期：2026-09-21

## 已确定基线

Jasper-Liao2026 的首页 Demo 作为协会官网主站的视觉与交互基线。对应 GitHub Issue #30 已由 PR #39 合并，主站参考提交为 `f758284`；当前 `main` 已同步到包含其他 Demo 合并结果的 `b320067`。

`prototype/` 保留 Jasper 的完整原型、素材、组件和验收截图，作为主站实现的设计参考。它仍是原型代码，不直接等同于生产应用。

## 其他 Demo 的去向

其他成员的方案继续保留在 `demo/` 与相关原型目录中，分别作为开发小组宣传网站的起点或视觉素材来源。宣传站点可以共享公开内容契约、Logo 和无障碍要求，但不把各自 Demo 整体覆盖到主站。

## 主站实现顺序

1. 从 Jasper 原型提炼生产外壳、导航、首页内容模型和响应式令牌。
2. 接入协会介绍、活动、成果、知识与加入入口，沿用仓库已审核的静态内容；飞书不进入网站运行时。
3. 为各宣传站点补充独立入口和部署说明，必要时只共享内容契约与品牌资源。
4. 每个可交付变更建立新的 GitHub issue 和 PR，记录真实检查、截图、来源与验收结果；已关闭的历史 issue 不继续堆叠新范围。

当前不提前引入登录、OJ、实时 ECPC 榜单或后台。四项全国性荣誉的证据缺口、成立年份冲突和未核实招新入口继续按内容治理规则处理。
