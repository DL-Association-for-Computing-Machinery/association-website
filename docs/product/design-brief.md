日期：2026-09-19。状态：候选参考，尚未定稿，无页面实现或渲染验收。用户已改为七人独立 Demo 与共同评审，按 [任务书](homepage-demo-round.md) 和 GitHub #25–#33 执行。本文颜色、布局与风格均不约束参赛方向；产品事实、素材真实性与可访问性仍需遵守。产品事实见 `PRODUCT.md`，真实文案与图片见 [素材包](../content/launch-content-pack.md)。

## 任务与受众

首页是 Persuade：让在手机上了解协会的新生知道“这里有什么、怎样参与”；活动详情与知识文章是 Read：方便完整阅读、核对日期、回到归档。第一行动为“了解加入方式”，第二行动为“浏览协会活动”。不让游客先登录飞书才能理解协会。

## 候选方向：校园技术成果展

保留正式 Logo 的深蓝、青色和少量暖色，把官网组织为一场有索引的校园成果展：协会名称和明确的学习邀请作为入口，真实合照形成主视觉，竞赛记录与活动年份提供可信证据，内容沿“认识协会 → 看见实践 → 选择参与方式”展开。浅底用于白天手机阅读，深蓝色区域建立协会识别；照片比装饰更醒目。

桌面首屏：左侧协会名称、两行以内主标题和两个入口；右侧完整比例合照；下方同屏可见紧凑荣誉摘要，展示赛事、级别与年份/届次，不用脱离来源的巨幅数字。手机按“名称 → 主标题 → 加入入口 → 荣誉摘要 → 合照”排列，保持两项已核验记录清楚可见。小屏不强行把四条荣誉、合照和活动列表全部压入一屏；近期活动紧接首屏，允许自然滚动。

记忆点是“同一群人，把兴趣变成真实的比赛、活动与知识”，不是代码雨、终端拟态或粒子动画。以年份索引串起活动，切换年份后保留标题、数量、选中状态和清除筛选操作；不需要滚动劫持。

## 最小视觉令牌提案

以下是官网界面颜色提案，不声称为学校官方品牌色。正式 Logo 原样使用；实现后根据真实渲染校验并记录 DESIGN.md。

| 角色     | 取值/约定                                                         | 用途                                               |
| -------- | ----------------------------------------------------------------- | -------------------------------------------------- |
| 页面底色 | #F5F8FC / #FFFFFF                                                 | 浅底阅读、白色内容面                               |
| 正文     | #14213D                                                           | 白底对比度 15.97:1                                 |
| 次级文字 | #536174                                                           | 页面底色对比度 5.92:1                              |
| 主色     | #173A70                                                           | 深蓝主按钮与标题区域；白字对比度 11.20:1           |
| 强调     | #007B83                                                           | 链接与选中线；白底对比度 5.05:1                    |
| 点缀     | #F4B544                                                           | 呼应 Logo 暖色，仅配深色字，不用白字承载正文       |
| 字体     | 系统中文无衬线；PingFang SC、Microsoft YaHei 等本机字体回退       | 无远程字体运行时依赖；等宽字体仅用于必要的代码示例 |
| 字号     | 正文 16–18；辅助 14；二级标题 24–32；主标题手机 32–40、桌面 48–64 | 中文主标题避免单字孤行；正文行高 1.7               |
| 间距     | 4、8、12、16、24、32、48、64                                      | 章节间距大于同组信息间距                           |
| 阅读宽度 | 全站内容不超过 1200；长文不超过 760                               | 手机边距 20；文字自然换行                          |
| 边角     | 控件 8，图片区 12                                                 | 不给所有区块套卡片；按标题和留白分组               |
| 交互     | 目标尺寸优先 44×44；可见焦点至少 2px 并与背景区分                 | 原生链接、按钮与表单优先；状态不能只靠颜色         |

## 页面与组件约定

| 页面       | 信息顺序                                         | 复用部件                        |
| ---------- | ------------------------------------------------ | ------------------------------- |
| 首页       | 学习邀请、荣誉摘要、活动回顾、学习方向、加入提示 | 导航、内容摘要、行动链接        |
| 协会介绍   | 简介、真实合照、日常活动、可核验历史节点         | 图文段落、年份列表              |
| 活动       | 年份/类型、日期排序、摘要、详情、返回列表        | 筛选控件、活动条目              |
| 成果       | 已核验赛事/级别/归属、来源说明                   | 荣誉条目；不做奖牌总数推断      |
| 知识与文章 | 分类、摘要、正文、来源、相关文章或返回           | 阅读容器、正文标题层级          |
| 加入我们   | 不同基础的参与路径、当前公告、公众号名称指引     | 文本引导；无有效 URL 时不造按钮 |

移动导航以原生按钮控制展开，语义状态与可见状态同步；Escape 可关闭并返回触发按钮。活动筛选优先原生选择控件；浏览返回时保留筛选状态。后台、登录、在线 OJ、实时榜单、学习平台均不进入本轮。

## 内容范围与异常状态

- 标题通常 8–32 个中文字符，较长标题自然换行，不以截断隐藏赛事名称；摘要约 40–100 字，正文容纳列表、图片与必要的代码示例。
- 荣誉组件支持 0–4 条真实内容。预览只显示已核验条目；0 条时隐藏宣传数字并提供成果说明。首版正式验收仍要求补齐四项，不以布局降级替代需求。
- 当前没有已核验的新报名活动，显示“活动回顾”；历史报名链接不作为当前行动入口。
- 没有筛选结果时说明当前条件并允许重置；图片缺失时保留标题和文字，不显示破图；来源为内部飞书时标注“协会资料整理”。
- 静态页面不设虚假的网络加载状态。链接检查失败时替换或撤下失效行动入口并保留文字说明。
- 成立时间疑点不在页面上显示争议原文；历史时间线从已有具体活动开始。
