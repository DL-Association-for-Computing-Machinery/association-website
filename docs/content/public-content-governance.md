# 公开内容模型与审核规范

## 内容类型

官网首版只维护五类公开内容：`Activity` 活动、`Achievement` 成果、`Article` 文章、`Person` 人物、`Link` 链接。

## 最小字段

每条内容至少包含：标题、摘要、正文或媒体、日期/年份、标签、来源 URL、公开状态、审核人和最后更新时间。图片额外记录版权/来源、尺寸和有意义的替代文本。

## 状态流转

```text
候选 → 整理中 → 待公开审核 → 可发布 → 已发布
                         └→ 退回修改
```

只有“可发布”和“已发布”内容可以进入构建；草稿、内部材料、脱敏不完整或来源不明的内容必须留在内部资料区。

## 审核清单

- [ ] 不含手机号、私人邮箱、身份证件、内部群信息或未授权名单。
- [ ] 人物姓名、照片、获奖信息和活动记录得到公开许可或负责人确认。
- [ ] 文章、图片、Logo 和外部链接有来源及版权说明。
- [ ] 日期、地点、报名状态和成绩经过事实核对。
- [ ] 图片有替代文本；链接有明确名称；正文没有只靠颜色传达的信息。
- [ ] GitHub PR 中保留内容来源和审核记录。

## 飞书与官网边界

飞书知识库保存原始资料和内部协作内容，GitHub 仓库保存经过筛选的公开内容。官网不在运行时读取飞书，也不把访问令牌放进前端或构建产物。
