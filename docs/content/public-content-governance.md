# 公开内容模型与审核规范

## 内容类型

官网首版只维护五类公开内容：`Activity` 活动、`Achievement` 成果、`Article` 文章、`Person` 人物、`Link` 链接。

## 最小字段

每条内容至少包含：稳定标识、标题、摘要、正文或媒体、日期/年份及精度、标签、来源 URL、公开状态、审核主体、审核结论和最后更新时间。无可靠事件日期时明确“未记录”，不得用抓取时间冒充。图片额外记录版权/来源、尺寸、文件校验值和有意义的替代文本。

## 状态流转

```text
候选 → 整理中 → AI 自审 → 可发布 → 已发布
                   ├→ 暂缓采用
                   └→ 退回修改
```

2026-09-19 用户确认：协会知识库内容可以作为计协官网素材，由 AI 自行提取、改编和审核，无需另设人工审核人或逐项索取协会素材授权。复用时保留协会来源；不将该授权描述为面向所有人的开源许可。

AI 完成去重、脱敏、来源标注、事实一致性检查与排版，审核记录可直接支持发布。遇到事实冲突、外部第三方素材权属不明或过期入口时，先自行交叉核验；仍无法解决则标记“暂缓采用”，记录缺失证据并继续其他条目，不设置强制人工确认流程。仅“可发布”和“已发布”映射为构建允许的 `public` 内容；所有其他状态均不进入产物。

## 审核清单

- [ ] 不含手机号、私人邮箱、身份证件、内部群信息或未授权名单。
- [ ] 人物姓名、照片、获奖信息和活动记录有知识库来源或公开来源；采用协会授权，自审记录标明提取范围。
- [ ] 文章、图片、Logo 和外部链接有来源及版权说明。
- [ ] 日期、地点、报名状态和成绩经过事实核对。
- [ ] 图片有替代文本；链接有明确名称；正文没有只靠颜色传达的信息。
- [ ] GitHub PR 中保留内容来源、AI 自审结论和暂缓采用记录（如有）。

## 飞书与官网边界

飞书知识库保存原始资料和内部协作内容，GitHub 仓库保存经过筛选的公开内容。官网不在运行时读取飞书，也不把访问令牌放进前端或构建产物。

原始年审附件、联系人表、账号、签名、未经筛选的完整导出只留在 Git 忽略的本地工作目录。官网正文使用改编稿与精选媒体，内部来源链接用于溯源，不用作游客必须登录才能完成的主要操作入口。
