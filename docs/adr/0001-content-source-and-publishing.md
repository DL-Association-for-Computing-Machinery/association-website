# ADR-0001：内容源与发布方式

## 状态

已接受（首版）

## 决策

首版官网使用内容驱动的静态发布。公开内容进入仓库后参与构建；飞书知识库通过人工导出或受控脚本同步，审核通过后再发布。

## 原因

静态发布简单、稳定、成本低，适合宣传官网；同时避免把飞书凭证、内部权限和未审核内容带入线上运行时。

## 后续变化

当内容更新频率或维护成本证明按需同步不足时，再增加飞书 Wiki API 的受控同步任务。同步任务必须保留来源核验、脱敏和发布门槛。

2026-09-19 补充：用户已授权 AI 自行采集、整理和审核协会知识库素材，无需人工逐项许可。事实疑点由 AI 交叉核验，仍无法确认的条目暂不采用；不阻塞其他素材。具体规则统一见 `docs/content/public-content-governance.md`。
