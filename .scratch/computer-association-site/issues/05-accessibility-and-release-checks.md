# 05: 完成可访问性与发布前检查

**What to build:** 发布负责人可以用一条命令检查关键页面的标题层级、键盘操作、焦点、表单标签、图片替代文本、颜色对比和链接状态，并得到可读结果。

**Blocked by:** 04: 完成活动、成果、知识和加入页面

**Status:** ready-for-agent

- [ ] 关键页面通过标题层级、跳过导航和可见焦点检查
- [ ] 移动端导航和加入入口可全程键盘操作
- [ ] 图片、链接和表单字段均有可访问名称或替代文本
- [ ] 运行构建、链接检查和静态预览检查
- [ ] 检查失败时返回非零状态，成功时输出发布摘要
