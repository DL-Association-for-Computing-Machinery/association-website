# 01: 建立公开内容样例与品牌令牌

**What to build:** 官网拥有一组经过脱敏、可公开展示的最小活动、成果、文章和加入信息，并有统一的颜色、字体、间距和媒体约定，后续页面可以直接使用这些内容。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**GitHub Issue:** [#2](https://github.com/DL-Association-for-Computing-Machinery/association-website/issues/2)

- [ ] 至少包含协会简介、近期活动、四项全国性竞赛荣誉、加入入口和一篇公开文章样例
- [ ] 每条内容包含标题、摘要、日期或年份、来源和公开审核状态
- [ ] 图片样例具备来源记录、尺寸约束和有意义的替代文本
- [ ] 建立最小设计令牌并通过构建或静态检查
