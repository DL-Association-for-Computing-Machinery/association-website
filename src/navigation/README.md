# navigation

站点导航结构的集中定义。让「导航项」只有一份来源，避免头部、移动菜单、
页脚各写一份而逐渐漂移。

## 文件

| 文件          | 说明                             |
| ------------- | -------------------------------- |
| `site-nav.ts` | `NavItem` 接口与 `SITE_NAV` 常量 |

## NavItem

```ts
export interface NavItem {
  /** 导航显示名称。 */
  title: string;
  /** 页内锚点，对应首页各区块的 id。 */
  url: string;
}
```

## 当前导航是页内锚点，不是路由

`SITE_NAV` 现在五项全部指向首页区块锚点：

| 名称     | 锚点          |
| -------- | ------------- |
| 关于协会 | `#about`      |
| 竞赛荣誉 | `#honors`     |
| 活动回顾 | `#activities` |
| 学习方向 | `#learning`   |
| 加入我们 | `#join`       |

**主站目前只有首页一个页面**，其余能力由各微服务子域承担（OJ、ECPC 等），
因此导航是页内锚点而非跨页路由。不生成指向未实现页面的链接——那会变成死链。

## 新增导航项时

- 锚点项：确认首页存在对应 `id`，否则链接点了没反应。
- 跨页项：等该页面在 `src/app/` 下真正建好后再加。
- 外部子域（OJ、ECPC）：子域地址确定后追加，使用真实 `<a href>` 并附描述性锚文本，
  **不要用客户端跳转**，便于搜索引擎跟随。
